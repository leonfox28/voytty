# Nerd Fonts icon attribution

LXGW Bright Code NF GB includes Nerd Fonts icons. The font files are supplied
unmodified by LXGW; their provenance and hashes are in NOTICE.txt.
LXGW does not specify the Nerd Fonts patcher version for this release.

The icon-project attribution below and NerdFonts-LICENSE.txt are retained
from Nerd Fonts v3.5.1. This identifies the icon projects and their licenses,
not a claim that LXGW used that patcher release or specific icon-set versions.

Source: https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1
