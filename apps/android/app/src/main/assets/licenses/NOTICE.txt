LXGW Bright Code NF GB — LXGW, the Klee Project Authors, GitHub,
and the Nerd Fonts icon contributors.

The four unmodified font files are bundled from LXGW Bright Code v2.922.
Upstream: https://github.com/lxgw/LxgwBright-Code/tree/v2.922/LxgwBrightCodeNFGB
Light is terminal normal; Regular is terminal bold. LightItalic and Italic
provide the corresponding terminal italic and bold-italic faces. Dim text
reduces intensity without changing the selected face.
